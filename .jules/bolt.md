## 2026-04-29 - Array instantiation inside component renders
**Learning:** Found static arrays being instantiated inside component renders. For instance `RouletteGame` instantiates an array via `Array.from({ length: 37 })` and `['red', 'black', 'even', 'odd', '1-18', '19-36']` inline inside the render, as well as chip values. This causes unnecessary garbage collection and memory allocation during React re-renders. It's better to hoist static definitions outside the component scope or use `utils/gameLogic.ts` definitions. I also see that they can be exported from gameLogic.ts.
**Action:** Extract static lists into constant variable definitions and export them from the utility file, or at least define them outside the component definition to prevent reallocation on every render cycle.
