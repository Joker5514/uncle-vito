## 2025-02-13 - [Hoist Static Arrays and Memoize Game Components]
**Learning:** [In this application, heavy components like `RouletteGame` and `BlackjackGame` contain static arrays defining game data (numbers, bets, chips) directly within the render function. This causes unnecessary memory allocations and garbage collection overhead on every render cycle. Moreover, these heavy game components are not memoized, leading to redundant re-renders when parent states change.]
**Action:** [Always hoist static arrays (e.g., game configurations, bet types, chip values) outside the React component scope to prevent redundant memory allocations. Wrap heavy, pure-like game components with `React.memo` to prevent unnecessary re-renders when parent components (like `TutorMode` or `App`) update unrelated states.]
