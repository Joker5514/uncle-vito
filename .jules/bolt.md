## 2024-11-20 - Avoid redundant object iteration in game payout calculations
**Learning:** In React components with frequent state updates (like betting games), calculating aggregate values (like `totalBet`) by reducing `Object.values(bets)` repeatedly can be inefficient. This codebase specifically had an anti-pattern where a `for...of` loop iterated over `currentBets`, and immediately afterwards, a separate `Object.values(currentBets).reduce()` repeated the iteration to calculate profit.
**Action:** When performing calculations that require iterating over an object's entries (e.g., determining payouts for different bet types), accumulate any required aggregates (like total wagered amount) within the *same* loop instead of chaining subsequent `Object.values().reduce()` calls. This reduces overhead in critical calculation paths like game loops.
