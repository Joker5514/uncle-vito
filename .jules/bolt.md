## 2024-06-19 - Removed unnecessary useEffect in BlackjackGame
**Learning:** Found a classic React anti-pattern in the codebase where derived state (`playerScore`, `dealerScore`) was being explicitly synchronized via `useState` and `useEffect` rather than simply calculated directly during the render pass. This caused the component to re-render twice on every hand update (once when the hand array changed, again when the `useEffect` updated the score state). Hand sizes are very small (rarely >5 cards) so recalculating on every render is extremely cheap and `useMemo` is not required.
**Action:** Always compute derived data directly in the render function where possible instead of synchronizing it with `useEffect`. For very trivial calculations (like summing an array of 2-5 ints), omit `useMemo` as the overhead of `useMemo` itself outweighs the calculation.
